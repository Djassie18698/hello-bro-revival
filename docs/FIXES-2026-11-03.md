# Fixes, 3 November 2026: the public server is always on

| What | Now |
|---|---|
| Public server always on | **ninjaonline** runs on a free Oracle Cloud computer instead of the owner's PC, so it's online day and night. It starts again by itself after a restart, and keeps a backup every 6 hours. Players keep the same game file (`HelloBro-ninjaonline.xapk`). How it's set up: [`CLOUD-SERVER.md`](CLOUD-SERVER.md) |
| Installing on a phone | The surest way is from a PC: turn on **USB debugging** on the phone, put `HelloBro-ninjaonline.xapk` and `INSTALL-WITH-USB.bat` (both on the Releases page) in one folder and double-click the .bat. It installs the game and its data, also on Android 14 and 15, over a cable or Wi-Fi |
| Android 14 / 15 | Game files made since 2 Nov install on new Android (they used to be refused), and logging in works there |
| Starter ninja | The ninja you pick when you make your character (Neji, Sakura or Shikamaru) is the one you get. Before, everyone got Shikamaru. The two players it happened to got their pick |
| Starter gift | The free "Exclusive Gift" no longer pops up after every level-up once you've claimed it |
| Arena | The **Claim** button for the daily arena reward shows on your own row |
| Tidier folder | Only the .bat files you click are on top; the server and its data are in the `server` folder. HOST-MY-SERVER no longer needs Tailscale |
