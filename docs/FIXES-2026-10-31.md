# Fixes of 31 October 2026

Everything fixed in one long session, in plain words: what was wrong, what it does now and how it was checked.
All of it comes from the two bug lists the owner and a friend filed in GitHub issues
[#2 (Bugfix list 1)](https://github.com/Djassie18698/hello-bro-revival/issues/2) and
[#3 (Bugfix list 2)](https://github.com/Djassie18698/hello-bro-revival/issues/3).

**How it was checked:** every fix was run on a throwaway database; most were also played in the real game on a BlueStacks
instance named "Claude" with a test server on its own port, so the owner's own server and save were never touched.
"Not seen in game" is written wherever something was only tested without the game.

Numbers marked **(ours)** are our own choice: the original value lived on the dead server and is lost.

---

## 1. Tools and workflow

| What | Detail |
|---|---|
| Bug reports | GitHub issue template (`.github/ISSUE_TEMPLATE/bug_report.yml`); lists #2 and #3 are kept as running comment threads |
| Update for friends | `UPDATE.bat` pulls the newest server from GitHub and keeps the save (`hellobro.db`) |
| Friend package | a zip with the server, tools and `START-HERE.txt` (no save, no private files) |
| Auto copy | `tools/sync_test_folder.sh` copies every push into the owner's `Hello Bro Locked Server` folder (the save is kept; the owner restarts the server) |
| Test emulator | only the BlueStacks instance **Claude**; its adb address is read from `tools/dev/emu.device` |
| Emulator ads | BlueStacks' game center app was suspended on the Claude instance so ad pages stop covering the game |

## 2. Training (Shinobi Exams and the other chapters)

| Problem | Now |
|---|---|
| Stages opened in the wrong order; "2-1 cleared opens 3-1" | The game counts **parts** (a group of stages that ends in a boss, 165 in total). Rows open top to bottom, a boss opens the next part, the last boss of a chapter opens the next chapter. Locked parts and chapters refuse fights |
| A boss had to be beaten 3 times | One boss win opens the next part |
| Boss fights cost gold / showed 5-10 challenges | 3 free fights a day, then the gold button works (10 gold **(ours)**) |
| Wins gave no item | Every win drops one low-tier item **(ours)**: normal stage Sage Stone III / 1-2 star equipment / 1-2 star shinobi; boss stage 3-star equipment or shinobi |
| Ramen showed no icon and a Chinese name on the victory card | Ramen is no longer dropped there (the game draws that card badly) |
| Reward wheel always landed on "work harder" | Lands on the card segment when a card dropped, otherwise luck **(ours)**: 40% work harder, 20% EXP x2, 20% silver x2, 20% gold (3 gold). Doubles are paid as one extra copy |
| Level jumped back (17, 16, 17) | The game credits a win's exp and silver itself; the server added them again. The server no longer repeats them and its exp starts at 0 at login like the game's |

## 3. Fights

| Problem | Now |
|---|---|
| "Enemies have 0 defense, then you lose" | The fight we describe always matches the result the server decided. Enemy attack, defense and life are real numbers |
| Crashes and broken counters ("Enemy Team -1/3", "2000K" cards) | The game subtracts as unsigned numbers and loses count if there are more rounds than cards. Won fights are one hit per enemy, lost fights one enemy hit per ninja of yours, and the attack is always above the defense |
| Spar bots could never be beaten | Bot strength is about even at equal level **(ours)** |
| Spar stamina "grudge" showed 10/3 with negative timers | Real grudge: maximum from the level, one point back every 2 hours **(ours)**, a spar costs 1 |
| Battles (tower) duel crashed 8 seconds in | The reply carried an empty reward id; it now carries a real drop |
| Number under the enemy portrait is 0 | This is how the game draws a hit that got through; putting a number there makes the game crash. Not changed |

## 4. Team and chains

| Problem | Now |
|---|---|
| No chain ever worked (e.g. Susa Indra with Sage of the Six Paths) | The chain table is used: partner in the team, worn equipment or ninjutsu, and leader chains ("All Shinobi +15%") add their percentage. Several chains add up. Susa Indra 525-720 became 811-1112 attack in the test |
| Chain list did not show which chains are active | Active chains turn red on the card detail screen (the server sends the active chain ids per slot) |

## 5. Rewards and claims

| Problem | Now |
|---|---|
| Login and level-up gifts showed "Sample Text" / paid invented gold | They pay the items shown on the button, from the game's own pack tables |
| Daily task chests were empty and paid made-up coins | The dialog shows the chest rewards and pays them once, only when the points are reached **(ours)**: 5000 silver, 20 gold, 10000 silver, 50 gold, 100 gold |
| Monthly sign-in: every slot claimable at once | One slot opens per day, in order |
| First-recharge claim, cumulative top-up rewards, "49$ gift" gave nothing or free gold | They need the real top-up total (top-ups are free but count), show the right state (can claim / not yet / claimed) and pay their items once |
| Ninjutsu packs paid 30000 silver | They give a real ninjutsu card of the stated star |

## 6. Recruits

| Problem | Now |
|---|---|
| Recruit was always free | Blue (150 gold) is free every 8 hours, purple (300 gold) every 24 hours, the button shows the countdown |
| "1 in 100" showed "claim -1 times" and was free | It is the original "use recruitment orders x 1": one order per card, 5 a day, shows "You have: N" |
| No pity counter | After 20 pulls without a 5-star the next one is sure (**(ours)**, resets after a 5-star) |

## 7. Not fixed, and why

| What | Why |
|---|---|
| Opening scene cannot be skipped; orange-card zoom on 10 pulls | Game code (`libgame.so`); the server cannot change it |
| Victory screen shows silver 0 | The screen reads the silver only from the reward we send, and the game credits it a second time, which would give double silver |
| Two filler cards next to a drop (Chinese names, no icon) | Picked by the game from its own table |
| 10-pull and some top-up screens | The original lists are lost; ours are marked above |
| Lost fights and the "ready chains" list | Lost spar played in game; the other lost-fight screens and the ready list were not seen in game |
