## 1. Breakthrough like the original screens

| Problem | Now |
|---|---|
| +1 cost 5 fragments and 50 000 silver | +1 costs **10 fragments** and **60 000 silver** (Kyuubi photo), or **250 000** for the strongest god cards (Six Paths Sasuke photo). ## 2. The wiki

A website about the game, like the Platinum Together wiki, served by the game server itself at **`/wiki/`**: on the public server
**[ninjaonlinereborn.com/wiki](https://ninjaonlinereborn.com/wiki/)** (its own address since the same evening, below), on your own server `http://<your address>:18080/wiki/`. No extra port, no password.

| Part | What is in it |
|---|---|
| Shinobi (493 cards) | stars, attack / defence type, level-1 stats and growth, built-in ninjutsu, **every chain** with the cards, gear and ninjutsu it needs (clickable), which cards it helps, and **how to get it** on this server (starter, recruit banners, mystery shop, fragments, story bosses, festivals, Limited Super Ninja, God Recruit, Ninja Test shop ...) |
| Gear (84), Ninjutsu (91), Seals (90), Pets (8), Items (39) | stats, sets, chains, Shop prices, where to get them |
| Sets (13) | gear and ninjutsu sets with their 2 / 3 / 4-piece bonuses |
| Training (19 chapters, 1 234 stages) | energy, EXP, silver, clears needed, each boss's enemies and its reward |
| Guides (27) | the Discord guides (install, how to play, questions) |
| Search | one box for everything, `/` jumps to it |

How it is made: `tools/build_wiki_icons.py` cuts the game's own icons into 5 picture sheets (WebP, 1.2 MB in total, so a page loads
about 10 files and never trips the server's flood guard); `tools/build_wiki.js` turns the game's tables, the server's event lists, the
Discord guides and the README news into `server/wiki/data.json`. `server/wikiserve.js` serves only files from `server/wiki`
(compressed, cached by version). `tools/dev/wiki-test.js` (in check.sh) checks every link and picture, that the data is up to date
with the tables and guides, and that no file outside the wiki can be fetched. Works on phones (menu button, two filters per row) and in dark mode.

## 3. The wiki gets its own address: ninjaonlinereborn.com

| Before | Now |
|---|---|
| The wiki was only at `http://ninjaonline.duckdns.org:18080/wiki/` (a port number in the link, no padlock) | **https://ninjaonlinereborn.com** (the owner bought the name at Namecheap). `www.ninjaonlinereborn.com`, `wiki.ninjaonline.duckdns.org` and the plain `ninjaonline.duckdns.org` (no port) in a browser lead there too. The old `:18080/wiki/` link keeps working |

How: a small web server (Caddy) on the Oracle machine answers on the normal web ports 80 and 443, serves the wiki files straight from the
server's copy of GitHub (so an update refreshes the wiki by itself) and gets and renews its free Let's Encrypt certificate by itself
(`tools/vps/wiki-site.sh`). Oracle's firewall got two new rules (ports 80 and 443, `docs/CLOUD-SERVER.md` step 3b); Namecheap has two A records
(`@` and `www`) pointing at the machine. The game itself still connects to `ninjaonline.duckdns.org:18080`: nobody needs a new game file.
Checked from outside: every name answers with a valid certificate, pictures cached a day, `.git`, `../` and the icon list refused, game server untouched.

## 5. Ninja Online Reborn on the login screen, and purple names

The owner asked: "change the login screen to Ninja Online Reborn" and "give me and Riskeric a special name in the leaderboard ... when I reset
my account, it still shows my name in glowing purple". Game update **28.0.43** (players tap Confirm once; the new logo shows from the next start).

| Before | Now |
|---|---|
| The login screen and the start logo said HELLO BRO | They show the **NINJA ONLINE / REBORN** logo of the website (the owner's logo with REBORN under it) |
| Every name in the No.1 Shinobi list (the 榜 scroll on Home) was black | Names on the owner's purple list **glow purple**: the name shifts between two purples with a soft light halo that pulses and a dark outline |
| A reset gave the player a new name | A purple name **belongs to the login**: after a reset the new character gets the same name back, and nobody else can make a character with it |

Later that night (game update **28.0.45**, owner: "make this name in home the same as in the leaderboard ... gold glowing for both of us"): the name at the
top of **Home** glows too, and the colour can be picked (8 quick colours or any colour, with a preview). A colour change shows the next time Home or the
list opens; a new name after reopening the game. DEAN and Riskeric glow **gold** on ninjaonline.

How: control panel > Players & items > pick the player > **✨ Glowing name** > type the name, pick a colour > Save name and colour (Remove takes it away). Only the
owner can do this (the item page that players can open has no such tab). The other rankings (Arena, War power, Tower, Wheel) are built into the
game app with one fixed color: the name shows there, but not purple. Checked in the game on the test server (login screen, #1 on the purple row,
a lower row on the light background); `tools/dev/smoke.js` checks the glow flag, the name after a reset, a second account trying the name,
and that players can't use the switch.
