# Fixes of 1 November 2026

What changed on 1 November, in plain words. Most of it comes from
[Bugfix list 3 (#4)](https://github.com/Djassie18698/hello-bro-revival/issues/4) and
[Bugfix list 4 (#5)](https://github.com/Djassie18698/hello-bro-revival/issues/5), plus owner requests.

**How it was checked:** on a throwaway database, and where it says "in game" on the BlueStacks instance **Claude** with a test
server on its own port. Numbers marked **(ours)** are our own choice: the original value is lost.

---

## 1. Server Manager (new)

| What | Detail |
|---|---|
| `START-SERVER.bat` | Coloured window with the server's addresses (Tailscale and home network), opens the Server Manager in your browser, starts the server again by itself when you press **Restart** |
| Server Manager page | `http://localhost:18080/manager`: online / offline, who is playing right now (and on which screen), players, uptime, save size, game-file version |
| Events on/off | A switch for every event the server runs: login rewards, level-up rewards, monthly sign-in, 7-day goals, world boss, lucky wheel, rock paper scissors, ninja treasure, millionaire, stage gift. Players see the change when they go back to the home screen |
| Announcement | Change the message players see in the game under **News → System** |
| Live log | Everything the server prints, with filters (hide game requests, errors only) |
| Backups | **Backup now** button and the list of backups (one is still made at every start) |
| Restart / Stop | With a confirm window. Restart only works when the server was started with `START-SERVER.bat` |
| Password | Same rule as the admin page: open, unless `ADMIN_PASSWORD` is set |

Tested: page, event switch (the wheel left the game's event list and came back), announcement (reached the game's bulletin),
restart (came back by itself), stop. In game: the lucky wheel button disappeared when switched off, and the announcement showed in News → System.

## 2. Cards

| Problem | Now |
|---|---|
| Rebirth 7 said "Your energy level is full" | The server asked for silver the original never asked. Now it is like the screen: **one copy of the same card OR the shown pills** (`newlifeconfig`) |
| Cards stopped at rebirth 6 | Shinobi go to **rebirth 8**, the most this game version shows (its code only draws rebirth outlines 1-8; rebirth 9 came in a later version) |
| Sage growth went up far too easily | The server now uses the game's own chance table (the % on the screen), silver cost and level drops on failure; max level 15. Extra-stone bonus +1% / +2% **(ours)** |
| Shinobi training crashed on the dropdown | The dropdown switches 1 time / 10 times; the server only sent the 1-time rows. Now both. Tested in game |
| Chains did not work for God cards | Names are compared without "(God)", spaces and dashes |
| Soul refinery did nothing | Cards turn into souls (refinery_info amounts) |
