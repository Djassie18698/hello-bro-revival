The game won't install on my phone or tablet

Questions

Install it from a PC with a USB cable: turn on USB debugging on the phone, put HelloBro-ninjaonline.xapk and INSTALL-WITH-USB.bat (both on the Releases page) in one folder and double-click the .bat. Step by step: #discord on Discord, chapter 2. That works on every phone, also Android 14 and 15.
Own server? Android 14 and newer refuse game files made before 2 Nov 2026: run UPDATE.bat, make a new game file with HOST-MY-SERVER.bat, and install that one the same way.
