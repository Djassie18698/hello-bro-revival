10b. Where do I type a gift code?

Questions

Now and then we share a gift code (in #updates or #announcement). In the game, tap the gear icon on Home (Settings), type the code under Invitation Code and tap Claim Award. Each code works once per player; the reward (gold, silver or a card) arrives at once. Letters can be typed big or small.
