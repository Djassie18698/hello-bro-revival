Hello Bro private server

The official Hello Bro / Ninja Online servers went offline years ago. We rebuilt the server, so the game can be played again, exactly like the original.

Play on our server Join Discord

Our public server

Anyone can join. It runs day and night, and it is free: top-ups cost nothing. You play with other players in the Arena, the Country War and Akatsuki guilds.

  • The same 493 shinobi, 19 story chapters and 1 234 stages as the original
  • The original events: Lucky Wheel, Millionaire, Ninja Treasure, Limited Super Ninja, the festivals and more
  • The strongest players are on the home page, live from the server

Host your own server

Want to play alone or only with friends? The server runs on a normal Windows PC. Download it from GitHub and double-click HOST-MY-SERVER.bat: it sets everything up and makes a game file for your own server.

Is this the official game?

No. It is a free fan revival of Hello Bro / Ninja Online (2015), made by its players. The game itself is the original app.
