Hello Bro APK download

The game file for Hello Bro, also called Ninja Online, the ninja card game from 2015. It connects to our free server by itself, so you can play again right away.

Download the game HelloBro-ninjaonline.xapk · 127 MB · free

What you get

The original 2015 app with its own cards, story and events, on a server rebuilt by players. 493 shinobi, 1 234 story stages, and top-ups cost nothing.

How to install it

  1. On a PC: install BlueStacks 5, then drag the downloaded file onto its window.
  2. On an Android phone: the file is an .xapk (the app plus its game data). Install it from a PC with a USB cable and our installer, INSTALL-WITH-USB.bat. This also works on new phones with Android 14 and up.
  3. Open Hello Bro, tap PLAY, pick your nation and your first ninja.

Questions

Is it safe?

It is the original app, changed only so it talks to our server, and built in the open: all the code is on GitHub.

Does it work on an iPhone?

No. The game only exists for Android. On a computer you can play it in BlueStacks.

My phone only runs 64-bit apps

The game is a 32-bit app. Players run it inside a virtual Android phone (VPhoneOS); the install guide explains how.

Can I get my old account back?

No. The old accounts were kept on the official servers, and those are gone, so everyone starts a new character.
